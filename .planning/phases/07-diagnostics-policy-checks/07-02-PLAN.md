<task type="auto">
  <name>Task 1: Implement evidence-gated policy evaluation</name>
  <files>tests/simulation_logs/policies.py</files>
  <action>
Create `tests/simulation_logs/policies.py` with `PolicyIssue`/`PolicyResult` dataclasses and helpers to evaluate tip reuse, mix, and air gap behavior. Parse CSV rows using existing helpers (`parse_csv_rows`, `detect_home_row`) to derive row intent (tip action, mix volume, air gap). Use normalized events and MatchResult row context for evidence checks:

- Tip reuse: If CSV `Tip Action` values exist, compare expected pickup/drop counts to observed `NormalizedTipPickupEvent`/`NormalizedTipDropEvent` counts and flag mismatches with row context. If tip action intent is absent, emit a warning and skip.
- Mix: If any row has `Mix Volume` > 0, require matching `NormalizedMixEvent` evidence for the corresponding destination labware/slot/well; if no mix events are present at all, warn and skip.
- Air gap: If any row has `Air Gap` > 0, ensure those rows are fully matched (no missing/mismatched ExpectedTransfer in MatchResult); treat missing/mismatch as policy violations. If no air gap intent exists, warn and skip.

Implement `evaluate_policies(expected_transfers, match_result, events, csv_path, settings)` that aggregates checks into a `PolicyResult` with `errors` and `warnings` and a `summary()` helper for test output.
  </action>
  <verify>uv run pytest tests/test_transfer_policies.py -k "policy"</verify>
  <done>Policy evaluation returns errors for violations and warnings for missing evidence, without failing on warning-only cases.</done>
</task>
