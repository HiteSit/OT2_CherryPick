Implement a transfer matcher that consumes ExpectedTransfer entries and normalized events. Create a MatchResult dataclass with fields like success, missing, extra, mismatched, and matched_count, plus helper methods for summary strings. Matching rules:
- Filter normalized events to aspirate/dispense only, ordered by sequence_index.
- Enforce strict order: iterate ExpectedTransfer list and advance through events without reordering.
- For each non-distribution transfer: require the next matching aspirate event (source labware_id/slot/well + aspirate_volume_ul), then the next matching dispense event (dest labware_id/slot/well + dispense_volume_ul).
- For distribution groups (shared group_id): require the first transfer in the group to match an aspirate event with volume == group_total_volume_ul, then match each per-dest dispense event in order; subsequent entries in the group do not re-match aspirate.
- For volume splitting: if expected.aspirate_volume_ul is larger than the next matching aspirate, allow multiple sequential aspirate+dispense pairs to accumulate to the expected volume as long as source/dest identifiers match and the summed volumes equal expected values exactly.
- Treat unmatched aspirate/dispense events as extra and fail by default (no tolerance), but expose a parameter allow_extra_events=False for future flexibility.
Update tests/simulation_logs/__init__.py to export the expectation builder and match_transfers function.
