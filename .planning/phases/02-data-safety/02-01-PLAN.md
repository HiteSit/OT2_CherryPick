  <action>
Add dirty state detection by comparing editorContent with original loaded content:

1. Add state to track the "original" content loaded from server:
   - `const [originalContent, setOriginalContent] = useState('')`

2. Update the useEffect that syncs csvContentQuery.data to also set originalContent:
   - When csvContentQuery.data changes and selectedFile is set, store the server content as originalContent
   - `setOriginalContent(csvContentQuery.data)` alongside existing `setEditorContent(csvContentQuery.data)`

3. Derive dirty state:
   - `const isDirty = selectedFile && editorContent !== originalContent`
   - Only consider dirty when a file IS selected (new/blank files are not "dirty" in this sense)

4. Add state for pending file selection (used when dirty):
   - `const [pendingFile, setPendingFile] = useState<string | null>(null)`
   - `const [showUnsavedModal, setShowUnsavedModal] = useState(false)`

5. Modify the Select onChange handler:
   - Instead of directly calling `setSelectedFile(value || '')`:
   - If isDirty and value differs from current selectedFile:
     - Store `setPendingFile(value || '')`
     - Open modal `setShowUnsavedModal(true)`
   - Else: proceed with `setSelectedFile(value || '')` as before

6. Add handler functions for modal actions:
   - `handleDiscardChanges`: close modal, set selectedFile to pendingFile, clear pendingFile
   - `handleCancelSwitch`: close modal, clear pendingFile (keep current file)

7. Reset originalContent when selection is cleared:
   - In handleClearSelection, also `setOriginalContent('')`
   - In handleRefresh, also reset originalContent (since selection is cleared)

Note: Do NOT touch handleTextChange or editor behavior - dirty detection is passive comparison only.

Create UnsavedChangesModal component following existing LabwareModal pattern:

1. Create new file `src/gui/frontend/src/components/wizard/csv/UnsavedChangesModal.tsx`:

```tsx
import { Modal, Button, Group, Text, Stack } from '@mantine/core'
import { IconAlertTriangle } from '@tabler/icons-react'

interface UnsavedChangesModalProps {
  opened: boolean
  onDiscard: () => void
  onCancel: () => void
  targetFile: string
}

export function UnsavedChangesModal({ opened, onDiscard, onCancel, targetFile }: UnsavedChangesModalProps) {
  return (
    <Modal
      opened={opened}
      onClose={onCancel}
      title="Unsaved Changes"
      centered
    >
      <Stack gap="md">
        <Group gap="sm">
          <IconAlertTriangle size={24} color="var(--mantine-color-yellow-6)" />
          <Text>You have unsaved changes that will be lost.</Text>
        </Group>
        <Text size="sm" c="dimmed">
          Switching to "{targetFile}" will discard your current edits.
        </Text>
        <Group justify="flex-end" gap="sm">
          <Button variant="default" onClick={onCancel}>
            Cancel
          </Button>
          <Button color="red" onClick={onDiscard}>
            Discard
          </Button>
        </Group>
      </Stack>
    </Modal>
  )
}
```

2. In CsvEditor.tsx, import and render the modal:
   - Add import: `import { UnsavedChangesModal } from './UnsavedChangesModal'`
   - Render modal at end of Stack (before closing tag):
     ```tsx
     <UnsavedChangesModal
       opened={showUnsavedModal}
       onDiscard={handleDiscardChanges}
       onCancel={handleCancelSwitch}
       targetFile={pendingFile || ''}
     />
     ```

3. Implement the handler functions in CsvEditor (if not already from Task 1):
   - handleDiscardChanges:
     ```tsx
     const handleDiscardChanges = () => {
       setShowUnsavedModal(false)
       if (pendingFile !== null) {
         setSelectedFile(pendingFile)
       }
       setPendingFile(null)
     }
     ```
   - handleCancelSwitch:
     ```tsx
     const handleCancelSwitch = () => {
       setShowUnsavedModal(false)
       setPendingFile(null)
     }
     ```

Button labels MUST be exactly "Discard" and "Cancel" per SAFE-02 requirement.
