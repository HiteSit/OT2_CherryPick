# Milestone v1.0: CSV File Selector

**Status:** ✅ SHIPPED 2026-01-21
**Phases:** 1-3
**Total Plans:** 3

## Overview

This feature adds a dropdown-based CSV file selector to the OT2 CherryPick GUI Configuration tab. Users can discover and select CSV files from a searchable dropdown, with immediate content loading into the editor views. The implementation leverages existing react-query hooks and Mantine components already present in the codebase.

## Phases

**Goal**: Users can select CSV files from a searchable dropdown and see content immediately loaded
**Depends on**: Nothing (first phase)
**Requirements**: SEL-01, SEL-02, SEL-03, SEL-04
**Plans**: 1 plan

Plans:
- [x] 01-01-PLAN.md — File selector with search, clear, refresh, and immediate content loading

## Milestone Summary

**Key Decisions:**

- Custom rightSection Group for both X and refresh buttons (avoids Mantine clearable conflict)
- Refresh always clears selection to prevent stale content
- Case-insensitive substring search (Mantine Select default)
- Alphabetical file sorting for predictable UI
- Dirty state derived from editorContent !== originalContent comparison
- Modal only appears when isDirty AND file selection differs from current
- Confirmation modal pattern with pending state for user decisions
- isEmpty derivation from csvListQuery.data.files.length === 0
- Conditional placeholder: "No CSV files found" vs "Choose a file or type to search"
- Filled variant for FileInput when empty to emphasize upload action
- Disabled dropdown when isEmpty or isLoading to prevent interaction

**Issues Resolved:**

- Users can now discover available CSV files without knowing filenames
- File selection immediately loads content without manual refresh
- Unsaved changes are protected with clear Discard/Cancel options
- Empty directory state provides clear feedback and emphasizes upload action
- All three features integrate seamlessly without state conflicts

**Issues Deferred:**

- START-01: Auto-select first file on page load (moved to v2)
- POLISH-01: Visual dirty indicator (asterisk or dot on filename)
- POLISH-02: Loading skeleton during file list fetch
- POLISH-03: Guidance message in empty state
- POLISH-04: File metadata tooltip showing modified date
- POLISH-05: Persist last selection across sessions (localStorage)

**Technical Debt Incurred:**

None - all implementations are production-ready with no shortcuts taken.
