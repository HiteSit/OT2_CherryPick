## End-to-End Flow Verification

### Flow 1: Happy Path - File Selection ✓

**Steps:**
1. User opens Configuration wizard → Transfer Map step
2. Sees dropdown with CSV files from gui_state/CSVs
3. Types to filter files
4. Selects file → content loads in SpreadSheet and Text views
5. Can clear selection or refresh file list

**Status:** ✓ COMPLETE - All steps verified, no breaks detected

**Data Flow:**
```
useCsvListQuery → csvOptions → Select.onChange → setSelectedFile
  → useCsvContentQuery → csvContentQuery.data → useEffect
  → setEditorContent + setCSV → SpreadSheet + Textarea + WizardContext
```

### Flow 2: Data Safety - Unsaved Changes ✓

**Steps:**
1. User selects file A → edits content → tries to select file B
2. Sees unsaved changes modal
3. Clicks Cancel → remains on file A with edits intact
4. OR clicks Discard → switches to file B, edits lost

**Status:** ✓ COMPLETE - All branches work correctly

**State Transitions:**
```
File A selected → originalContent = "A content"
User edits → editorContent = "A modified"
isDirty = true → User selects B → pendingFile = "B", modal opens

[Cancel Branch]
  modal closes → selectedFile still "A" → edits preserved

[Discard Branch]
  selectedFile = "B" → new content loads → originalContent = "B content"
```

### Flow 3: Empty State ✓

**Steps:**
1. User has no CSV files in directory
2. Sees disabled dropdown with "No CSV files found"
3. Upload button emphasized (filled variant)
4. Can still use editor for manual CSV creation

**Status:** ✓ COMPLETE - Empty state orthogonal to editor functionality

**Logic:**
```
csvListQuery.data.files.length === 0 → isEmpty = true
  → dropdown.disabled = true
  → placeholder = "No CSV files found"
  → FileInput.variant = "filled"

BUT editor features unchanged:
  - Add Row, Remove Row, Tabs, Spreadsheet all functional
```

### Flow 4: Cross-Phase Combined Scenarios ✓

**Scenario A:** Empty state → Upload → Unsaved changes protection
```
isEmpty = true → Upload file → isEmpty = false → dropdown enabled
  → Select file → Edit → Try switch → Modal appears
```
✓ VERIFIED

**Scenario B:** File selection → Refresh with unsaved changes
```
Select file → Edit → isDirty = true → Click refresh
  → handleRefresh clears selection (bypasses dirty check per requirement)
```
✓ VERIFIED

**Scenario C:** Empty state doesn't break dirty detection
```
isEmpty = true → Manual CSV creation → isDirty = false
  (correct: no file selected to "switch from")
```
✓ VERIFIED
